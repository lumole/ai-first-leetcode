# 向量相似度与距离

## L2 归一化 与 Min-Max 归一化

CodeKy：[1440. L2 范数](https://codeky.online/problem/1680)；[1542. Min-Max 特征缩放](https://codeky.online/problem/1786)
Deep-ML：[L2 Normalization Along an Axis](https://www.deep-ml.com/problems/1022)；[Min-Max Scaling of Feature Values](https://www.deep-ml.com/problems/112)
LeetGPU：L2 归一化、Min-Max 归一化均未找到直接对应题目

L2 归一化把每个向量除以自身的 L2 范数，归一化后模长为 1，常用在检索前把 embedding 统一到单位球面上，这样点积就等于余弦相似度。Min-Max 归一化把每一列线性缩放到 0 到 1 之间，用在特征量纲不一致时。两者都要在分母上加一个极小量防止除零。

```python
import numpy as np

def l2_normalize(x, axis=-1, eps=1e-12):
    # 每个向量除以自身 L2 范数，归一化后模长为 1
    norm = np.linalg.norm(x, ord=2, axis=axis, keepdims=True)
    return x / np.maximum(norm, eps)

def min_max_normalize(x, axis=0, eps=1e-12):
    # 把每一列线性缩放到 [0, 1]
    lo = x.min(axis=axis, keepdims=True)
    hi = x.max(axis=axis, keepdims=True)
    return (x - lo) / np.maximum(hi - lo, eps)

# 输入输出样例
print(l2_normalize(np.array([3.0, 4.0])))   # [0.6 0.8]
print(min_max_normalize(np.array([[1.0, 10.0], [3.0, 30.0], [5.0, 20.0]])))
# [[0.  0. ]
#  [0.5 1. ]
#  [1.  0.5]]
```

## 余弦相似度

CodeKy：[1374. 余弦相似度](https://codeky.online/problem/1613)
Deep-ML：[Calculate Cosine Similarity Between Vectors](https://www.deep-ml.com/problems/76)
LeetGPU：未找到直接对应题目

余弦相似度是两个向量夹角的余弦，等于点积除以两者模长的乘积，取值在 -1 到 1 之间，只看方向不看长度。批量场景先把每行 L2 归一化，再做一次矩阵乘法就能得到两两相似度，比逐对循环快很多。

$\cos(a, b) = \frac{a\cdot b}{\|a\|\,\|b\|}$

```python
import numpy as np

def cosine_similarity(a, b, eps=1e-8):
    # 点积除以两个向量模长的乘积
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b) + eps)

def cosine_similarity_matrix(A, B, eps=1e-8):
    # A: (n, d)，B: (m, d)，返回 (n, m) 的两两相似度
    A = A / (np.linalg.norm(A, axis=1, keepdims=True) + eps)
    B = B / (np.linalg.norm(B, axis=1, keepdims=True) + eps)
    return A @ B.T

# 输入输出样例
print(cosine_similarity(np.array([1.0, 0.0, 1.0]), np.array([1.0, 1.0, 0.0])))  # 0.49999...（约 0.5）
print(cosine_similarity_matrix(np.array([[1.0, 0.0], [0.0, 1.0]]), np.array([[1.0, 1.0]])))
# [[0.70710677]
#  [0.70710677]]
```

## 欧氏距离

CodeKy：[1336. 两点欧氏距离](https://codeky.online/problem/1575)
Deep-ML：未找到直接对应题目
LeetGPU：未找到直接对应题目

欧氏距离是两点间直线距离，对各维差的平方求和再开方。批量算两组向量的两两距离时，用 $\|a-b\|^2 = \|a\|^2 + \|b\|^2 - 2a\cdot b$ 展开，把成对的循环换成一次矩阵乘法；浮点误差可能让平方距离出现极小的负值，开方前要截到 0。

$d(a, b) = \sqrt{\sum_i (a_i - b_i)^2}$

```python
import numpy as np

def euclidean_distance(a, b):
    return np.sqrt(np.sum((a - b) ** 2))

def euclidean_distance_matrix(A, B):
    # 用 ||a-b||^2 = ||a||^2 + ||b||^2 - 2 a·b 避免成对循环
    a2 = np.sum(A ** 2, axis=1, keepdims=True)    # (n, 1)
    b2 = np.sum(B ** 2, axis=1, keepdims=True).T  # (1, m)
    d2 = a2 + b2 - 2 * A @ B.T
    return np.sqrt(np.maximum(d2, 0))             # 截到 0，防浮点误差出现负数

# 输入输出样例
print(euclidean_distance(np.array([0.0, 0.0]), np.array([3.0, 4.0])))   # 5.0
print(euclidean_distance_matrix(np.array([[0.0, 0.0], [1.0, 1.0]]), np.array([[3.0, 4.0]])))
# [[5.        ]
#  [3.60555128]]
```
