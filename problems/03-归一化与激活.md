### 手写 BatchNorm

CodeKy：[3083. BatchNorm](https://codeky.online/problem/3751)
Deep-ML：[BatchNorm1d Forward with Bessel's Correction](https://www.deep-ml.com/problems/1003)
LeetGPU：[Batch Normalization](https://leetgpu.com/challenges/batch-normalization)

BatchNorm 沿 batch 维对每个特征通道做归一化，所以统计量依赖整个 mini-batch。训练时用当前 batch 的均值方差，并维护一组滑动平均的 running_mean、running_var；推理时直接用滑动平均，这样单个样本也能跑。归一化后再用可学习的 gamma、beta 做缩放和平移。

```python
import torch
import torch.nn as nn

class BatchNorm1d(nn.Module):
    def __init__(self, num_features, eps=1e-5, momentum=0.1):
        super().__init__()
        self.eps, self.momentum = eps, momentum
        self.gamma = nn.Parameter(torch.ones(num_features))
        self.beta = nn.Parameter(torch.zeros(num_features))
        self.register_buffer('running_mean', torch.zeros(num_features))
        self.register_buffer('running_var', torch.ones(num_features))

    def forward(self, x):
        # x: (B, C)，沿 batch 维统计每个特征
        if self.training:
            mean = x.mean(0)
            var = x.var(0, unbiased=False)
            self.running_mean = (1 - self.momentum) * self.running_mean + self.momentum * mean
            self.running_var = (1 - self.momentum) * self.running_var + self.momentum * var
        else:
            mean, var = self.running_mean, self.running_var
        x_hat = (x - mean) / torch.sqrt(var + self.eps)
        return self.gamma * x_hat + self.beta

# 输入输出样例：归一化后每个特征列的均值约 0、方差约 1
bn = BatchNorm1d(num_features=4)
x = torch.randn(16, 4)                  # (batch=16, features=4)
y = bn(x)
print(y.shape, y.mean(0).abs().max().item() < 1e-5)   # torch.Size([16, 4]) True
```

### 手写 LayerNorm

CodeKy：[1389. 层归一化](https://codeky.online/problem/1628)
Deep-ML：[Implement LayerNorm from Scratch](https://www.deep-ml.com/problems/908)
LeetGPU：[Layer Normalization](https://leetgpu.com/challenges/layer-normalization)

LayerNorm 沿特征维对每个样本独立归一化，不依赖 batch，统计量只来自这一个样本自己。它没有训练和推理两套行为，实现比 BatchNorm 简单，也不需要维护滑动平均。

```python
import torch
import torch.nn as nn

class LayerNorm(nn.Module):
    def __init__(self, d_model, eps=1e-5):
        super().__init__()
        self.eps = eps
        self.gamma = nn.Parameter(torch.ones(d_model))
        self.beta = nn.Parameter(torch.zeros(d_model))

    def forward(self, x):
        # 沿最后一维（特征维）统计，每个样本独立归一化
        mean = x.mean(-1, keepdim=True)
        var = x.var(-1, unbiased=False, keepdim=True)
        x_hat = (x - mean) / torch.sqrt(var + self.eps)
        return self.gamma * x_hat + self.beta

# 输入输出样例
ln = LayerNorm(d_model=4)
x = torch.randn(2, 3, 4)                 # (batch=2, seq=3, d_model=4)
print(ln(x).shape)                       # torch.Size([2, 3, 4])
```

### BatchNorm 与 LayerNorm 的区别是什么？

CodeKy：未找到直接对应题目
Deep-ML：未找到直接对应题目
LeetGPU：未找到直接对应题目

两者都是减均值除标准差再做仿射变换，区别只在统计量沿哪个维度算。BatchNorm 沿 batch 维统计，依赖 batch 大小，batch 小时统计噪声大，而且序列长度可变的 NLP 任务里同一位置的样本数不固定，所以不好用；它还要区分训练和推理，靠滑动平均。LayerNorm 沿特征维统计，每个样本自给自足，与 batch 大小和序列长度都无关，训练推理行为一致，因此 Transformer 普遍用 LayerNorm，而 CNN 视觉任务更常用 BatchNorm。

| 维度 | BatchNorm | LayerNorm |
| --- | --- | --- |
| 统计方向 | 沿 batch 维（每个特征） | 沿特征维（每个样本） |
| 是否依赖 batch | 是 | 否 |
| 训练/推理 | 不同（靠滑动平均） | 一致 |
| 典型场景 | CNN、视觉 | Transformer、NLP |

## RMSNorm

CodeKy：[2082. RMSNorm 归一化](https://codeky.online/problem/2597)
Deep-ML：[Implement RMSNorm (Root Mean Square Layer Normalization)](https://www.deep-ml.com/problems/372)
LeetGPU：[RMS Normalization](https://leetgpu.com/challenges/rms-normalization)

RMSNorm 是 LayerNorm 的简化版，只用均方根做缩放，既不减均值也没有 beta 偏置。它假设重新中心化（减均值）对效果帮助不大，去掉后计算更省，因此被很多大模型采用。只保留一个可学习的 gamma。

$\mathrm{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum_i x_i^2 + \epsilon}}\cdot \gamma$

```python
import torch
import torch.nn as nn

class RMSNorm(nn.Module):
    def __init__(self, d_model, eps=1e-6):
        super().__init__()
        self.eps = eps
        self.gamma = nn.Parameter(torch.ones(d_model))

    def forward(self, x):
        # 只用均方根缩放，不减均值、不加偏置
        rms = torch.sqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)
        return self.gamma * x / rms

# 输入输出样例
norm = RMSNorm(d_model=4)
x = torch.randn(2, 3, 4)                 # (batch=2, seq=3, d_model=4)
print(norm(x).shape)                     # torch.Size([2, 3, 4])
```

## Dropout

CodeKy：[1557. Dropout 前向](https://codeky.online/problem/1803)
Deep-ML：[Implement Dropout from Scratch](https://www.deep-ml.com/problems/901)
LeetGPU：未找到直接对应题目

Dropout 训练时按概率 p 随机把神经元置零，打断神经元之间的共适应，缓解过拟合。主流实现是 inverted dropout：训练时把保留下来的元素除以 (1-p)，让输出期望和不 dropout 时一致，推理阶段就能直接直通、不做任何缩放。关键是只在训练时生效。

```python
import torch
import torch.nn as nn

class Dropout(nn.Module):
    def __init__(self, p=0.5):
        super().__init__()
        self.p = p

    def forward(self, x):
        if not self.training or self.p == 0:
            return x                              # 推理时直通，不缩放
        # inverted dropout：随机置零并除以保留概率，保持期望不变
        mask = (torch.rand_like(x) > self.p).float()
        return x * mask / (1 - self.p)

# 输入输出样例
drop = Dropout(p=0.5)
x = torch.ones(2, 6)
drop.train(); print(drop(x))   # 约一半元素为 0，其余为 2.0（即 1/(1-0.5)）
drop.eval();  print(drop(x))   # 推理直通，全为 1.0
```

## ReLU 与 GELU

CodeKy：[1351. ReLU 激活](https://codeky.online/problem/1590)；GELU 未找到直接对应题目
Deep-ML：[Implement ReLU Activation Function](https://www.deep-ml.com/problems/42)；[GeLU Activation Function](https://www.deep-ml.com/problems/147)
LeetGPU：[ReLU](https://leetgpu.com/challenges/relu)；GELU 未找到直接对应题目

ReLU 把负数截成 0，正数原样保留，计算简单、正区间导数恒为 1，能缓解梯度消失。GELU 用标准正态的累积分布函数加权输入，在 0 附近平滑过渡，负值不是硬截断而是按概率部分保留，是 Transformer 里的主流激活。GELU 的精确式含误差函数，工程上常用下面的 tanh 近似。

$\mathrm{GELU}(x) = x\cdot\Phi(x) \approx 0.5x\left(1 + \tanh\!\left[\sqrt{\tfrac{2}{\pi}}\left(x + 0.044715x^3\right)\right]\right)$

```python
import torch
import math

def relu(x):
    return torch.maximum(x, torch.zeros_like(x))

def gelu(x):
    # tanh 近似形式，和大模型里常用的实现一致
    return 0.5 * x * (1 + torch.tanh(
        math.sqrt(2 / math.pi) * (x + 0.044715 * x.pow(3))))

# 输入输出样例
x = torch.tensor([-1.0, 0.0, 1.0, 2.0])
print(relu(x))   # tensor([0., 0., 1., 2.])
print(gelu(x))   # tensor([-0.1588,  0.0000,  0.8412,  1.9546])
```

## Sigmoid 与 Tanh

CodeKy：[1383. Sigmoid 激活函数](https://codeky.online/problem/1622)；[1215. Tanh 激活函数](https://codeky.online/problem/1453)
Deep-ML：[Sigmoid Activation Function Understanding](https://www.deep-ml.com/problems/22)；[Implement the Tanh Activation Function](https://www.deep-ml.com/problems/264)
LeetGPU：[Sigmoid Activation](https://leetgpu.com/challenges/sigmoid-activation)；Tanh 未找到直接对应题目

Sigmoid 把实数映射到 (0,1)，常用作二分类输出或门控；Tanh 把输出映射到 (-1,1)，以零为中心，收敛比 Sigmoid 快。两者在两端都会饱和、导数趋零，深层网络里容易梯度消失，所以隐藏层更常用 ReLU 系列，这两个多见于输出层和门控单元。

$\sigma(x)=\frac{1}{1+e^{-x}},\qquad \tanh(x)=\frac{e^{x}-e^{-x}}{e^{x}+e^{-x}}$

```python
import torch

def sigmoid(x):
    return 1 / (1 + torch.exp(-x))

def tanh(x):
    return (torch.exp(x) - torch.exp(-x)) / (torch.exp(x) + torch.exp(-x))

# 输入输出样例
x = torch.tensor([-1.0, 0.0, 1.0])
print(sigmoid(x))   # tensor([0.2689, 0.5000, 0.7311])
print(tanh(x))      # tensor([-0.7616,  0.0000,  0.7616])
```

## CrossEntropy Loss

CodeKy：[3051. 手撕CrossEntropy](https://codeky.online/problem/3719)
Deep-ML：[Numerically Stable Cross-Entropy](https://www.deep-ml.com/problems/914)
LeetGPU：[Categorical Cross Entropy Loss](https://leetgpu.com/challenges/categorical-cross-entropy-loss)

分类交叉熵等于对 logits 做 log_softmax 再取目标类的负对数概率。直接先 softmax 再取 log 会有数值问题，稳定的写法是把 log_softmax 展开成 $x_i - \log\sum_j e^{x_j}$ ，并在指数前减去每行最大值。这一题考的就是把 softmax、log、负对数似然三步合并并保证数值稳定。

$\mathcal{L} = -\frac{1}{N}\sum_{n} \log \frac{e^{x_{n,y_n}}}{\sum_j e^{x_{n,j}}}$

```python
import torch

def cross_entropy(logits, target):
    # logits: (N, C)，target: (N,) 是类别下标
    logits = logits - logits.max(dim=-1, keepdim=True).values   # 数值稳定
    log_prob = logits - torch.log(torch.exp(logits).sum(-1, keepdim=True))
    nll = -log_prob[torch.arange(len(target)), target]          # 取目标类的负对数概率
    return nll.mean()

# 输入输出样例
logits = torch.tensor([[2.0, 0.5, 0.1], [0.2, 1.5, 0.3]])
target = torch.tensor([0, 1])
print(cross_entropy(logits, target))   # tensor(0.3851)
```

## MSE 与 BCE Loss

CodeKy：[3104. MSELoss 均方误差](https://codeky.online/problem/3772)；[3105. BCEWithLogitsLoss](https://codeky.online/problem/3773)
Deep-ML：[Mean Squared Error from Scratch](https://www.deep-ml.com/problems/1228)；[Implement Binary Cross-Entropy Loss](https://www.deep-ml.com/problems/263)
LeetGPU：[Mean Squared Error](https://leetgpu.com/challenges/mean-squared-error)；BCE 未找到直接对应题目

MSE 用在回归，是预测和目标差的平方的均值。BCE 用在二分类，输入是 sigmoid 后的概率和 0/1 标签，本质是交叉熵在两类上的特例；实现要点是对概率做 clamp，防止概率取到 0 或 1 时 log 溢出。

$\mathrm{MSE} = \frac{1}{N}\sum_n (\hat{y}_n - y_n)^2,\qquad \mathrm{BCE} = -\frac{1}{N}\sum_n \big[y_n\log p_n + (1-y_n)\log(1-p_n)\big]$

```python
import torch

def mse_loss(pred, target):
    # 回归任务：预测与目标差的平方的均值
    return ((pred - target) ** 2).mean()

def bce_loss(prob, target, eps=1e-12):
    # 二分类：prob 是 sigmoid 后的概率，target 是 0/1 标签
    prob = prob.clamp(eps, 1 - eps)        # 防止 log(0)
    return -(target * torch.log(prob) + (1 - target) * torch.log(1 - prob)).mean()

# 输入输出样例
print(mse_loss(torch.tensor([2.0, 0.0]), torch.tensor([1.0, 0.0])))   # tensor(0.5000)
print(bce_loss(torch.tensor([0.9, 0.2]), torch.tensor([1.0, 0.0])))   # tensor(0.1643)
```
