# 注意力机制

## Softmax

CodeKy：[3050. Softmax 数值稳定](https://codeky.online/problem/3718)
Deep-ML：[Numerically Stable Softmax](https://www.deep-ml.com/problems/1227)
LeetGPU：[Softmax](https://leetgpu.com/challenges/softmax)

Softmax 把一组实数变成和为 1 的概率分布。直接套公式会因为 $e^{x}$ 在 x 较大时溢出，标准做法是先减去每一行的最大值再取指数，结果和原式严格相等但不会溢出，这一步是面试最常被追问的点。

$\mathrm{softmax}(x)_i = \frac{e^{x_i}}{\sum_j e^{x_j}}$

```python
import numpy as np

def softmax(x, axis=-1):
    # 减去最大值做数值稳定，避免 exp 溢出，结果与原式相等
    x = x - np.max(x, axis=axis, keepdims=True)
    e = np.exp(x)
    return e / np.sum(e, axis=axis, keepdims=True)

# 输入输出样例
x = np.array([1.0, 2.0, 3.0])
print(softmax(x))   # [0.09003057 0.24472847 0.66524096]
```

## Scaled Dot-Product Attention

CodeKy：[1230. Scaled Dot-Product Attention](https://codeky.online/problem/1469)
Deep-ML：[Build Scaled Dot-Product Attention](https://www.deep-ml.com/problems/490)
LeetGPU：[Softmax Attention](https://leetgpu.com/challenges/softmax-attention)

注意力用 Query 和所有 Key 的点积衡量相关性，除以 $\sqrt{d_k}$ 缩放后过 Softmax 得到权重，再对 Value 加权求和。除以 $\sqrt{d_k}$ 是因为点积的方差随维度增长，分数过大会把 Softmax 推到饱和区导致梯度消失。mask 在 Softmax 之前把需要屏蔽的位置填成负无穷，过 Softmax 后这些位置的权重就变成 0。

$\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^{T}}{\sqrt{d_k}}\right)V$

```python
import torch
import torch.nn.functional as F
import math

def scaled_dot_product_attention(q, k, v, mask=None):
    # q, k, v 形状均为 (batch, heads, seq, d_k)
    d_k = q.size(-1)
    scores = q @ k.transpose(-2, -1) / math.sqrt(d_k)   # (batch, heads, seq, seq)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    attn = F.softmax(scores, dim=-1)
    return attn @ v, attn

# 输入输出样例
q = torch.randn(2, 4, 5, 8)                 # (batch=2, heads=4, seq=5, d_k=8)
out, attn = scaled_dot_product_attention(q, q, q)
print(out.shape, attn.shape)                # torch.Size([2, 4, 5, 8]) torch.Size([2, 4, 5, 5])
```

## Causal Mask

CodeKy：[1554. 因果掩码分数](https://codeky.online/problem/1800)
Deep-ML：[Construct Causal Attention Mask via tril and triu Methods](https://www.deep-ml.com/problems/965)
LeetGPU（相关）：[Causal Self-Attention](https://leetgpu.com/challenges/causal-self-attention)

自回归生成时位置 i 只能看到 i 及之前的 token，靠一个下三角矩阵实现：下三角为 1 表示可见，上三角为 0 表示屏蔽。把它传给上面的注意力函数，未来位置的分数会被填成负无穷。

```python
import torch

def causal_mask(seq_len):
    # 下三角（含对角线）为 True，上三角为 False
    return torch.tril(torch.ones(seq_len, seq_len)).bool()

# 输入输出样例
print(causal_mask(3))
# tensor([[ True, False, False],
#         [ True,  True, False],
#         [ True,  True,  True]])
```

## Multi-Head Attention

CodeKy：[3055. 手撕Multi-Head Attention](https://codeky.online/problem/3723)
Deep-ML：[Implement Multi-Head Self-Attention](https://www.deep-ml.com/problems/904)
LeetGPU：[Multi-Head Attention](https://leetgpu.com/challenges/multi-head-attention)

多头注意力把 d_model 维拆成 n_heads 个子空间，每个头在自己的子空间里独立做注意力，最后拼接再过一个输出投影。这样不同的头能关注不同的依赖模式。实现的关键是 reshape 加 transpose 把维度排成 (batch, heads, seq, d_k)，算完再合并回去。

```python
import torch
import torch.nn as nn
import math

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        assert d_model % n_heads == 0
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        self.w_q = nn.Linear(d_model, d_model)
        self.w_k = nn.Linear(d_model, d_model)
        self.w_v = nn.Linear(d_model, d_model)
        self.w_o = nn.Linear(d_model, d_model)

    def forward(self, x, mask=None):
        B, T, _ = x.shape
        # 投影后拆头：(B, T, d_model) -> (B, n_heads, T, d_k)
        q = self.w_q(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        k = self.w_k(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        v = self.w_v(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        scores = q @ k.transpose(-2, -1) / math.sqrt(self.d_k)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float('-inf'))
        attn = scores.softmax(dim=-1)
        out = attn @ v                               # (B, n_heads, T, d_k)
        out = out.transpose(1, 2).reshape(B, T, -1)  # 合并多头
        return self.w_o(out)

# 输入输出样例
mha = MultiHeadAttention(d_model=512, n_heads=8)
x = torch.randn(2, 10, 512)                          # (batch=2, seq=10, d_model=512)
print(mha(x).shape)                                  # torch.Size([2, 10, 512])
```

## Grouped-Query Attention

CodeKy：[3058. 手撕Grouped-Query Attention](https://codeky.online/problem/3726)
Deep-ML：[Implement Grouped Query Attention (GQA)](https://www.deep-ml.com/problems/391)
LeetGPU：[Grouped Query Attention](https://leetgpu.com/challenges/grouped-query-attention)

GQA 介于 MHA 和 MQA 之间。MHA 每个头有独立的 K/V，KV Cache 占显存大；MQA 让所有 Q 头共享一组 K/V，省显存但质量略降；GQA 把 Q 头分成几组，每组共享一组 K/V，在两者之间取平衡。现代大模型大多用 GQA。实现的关键是把少量 KV 头复制到和 Q 头数对齐，MQA 就是 n_kv_heads 取 1 的特例。

```python
import torch
import torch.nn as nn
import math

class GroupedQueryAttention(nn.Module):
    def __init__(self, d_model, n_heads, n_kv_heads):
        super().__init__()
        assert n_heads % n_kv_heads == 0
        self.n_heads = n_heads
        self.n_kv_heads = n_kv_heads
        self.n_rep = n_heads // n_kv_heads        # 每个 KV 头被多少个 Q 头共享
        self.d_k = d_model // n_heads
        self.w_q = nn.Linear(d_model, n_heads * self.d_k)
        self.w_k = nn.Linear(d_model, n_kv_heads * self.d_k)
        self.w_v = nn.Linear(d_model, n_kv_heads * self.d_k)
        self.w_o = nn.Linear(d_model, d_model)

    def forward(self, x, mask=None):
        B, T, _ = x.shape
        q = self.w_q(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        k = self.w_k(x).view(B, T, self.n_kv_heads, self.d_k).transpose(1, 2)
        v = self.w_v(x).view(B, T, self.n_kv_heads, self.d_k).transpose(1, 2)
        # 把每个 KV 头复制 n_rep 份，对齐 Q 的头数
        k = k.repeat_interleave(self.n_rep, dim=1)
        v = v.repeat_interleave(self.n_rep, dim=1)
        scores = q @ k.transpose(-2, -1) / math.sqrt(self.d_k)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float('-inf'))
        attn = scores.softmax(dim=-1)
        out = (attn @ v).transpose(1, 2).reshape(B, T, -1)
        return self.w_o(out)

# 输入输出样例：8 个 Q 头共享 2 个 KV 头（MQA 是 n_kv_heads=1 的特例）
gqa = GroupedQueryAttention(d_model=512, n_heads=8, n_kv_heads=2)
x = torch.randn(2, 10, 512)
print(gqa(x).shape)                                  # torch.Size([2, 10, 512])
```

## Cross-Attention

CodeKy：[3054. 手撕Cross-Attention](https://codeky.online/problem/3722)
Deep-ML：未找到直接对应题目
LeetGPU：[Multi-Head Cross-Attention](https://leetgpu.com/challenges/multi-head-cross-attention)

Cross-Attention 和 self-attention 唯一的区别是 Q 来自一个序列、K 和 V 来自另一个序列。encoder-decoder 结构里它让 decoder 在生成每个词时关注整个输入，所以 Q 来自 decoder、K/V 来自 encoder 的输出，两个序列长度可以不同，注意力矩阵是 Tq×Tk 的长方形。

```python
import torch
import torch.nn as nn
import math

class CrossAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        self.w_q = nn.Linear(d_model, d_model)
        self.w_k = nn.Linear(d_model, d_model)
        self.w_v = nn.Linear(d_model, d_model)
        self.w_o = nn.Linear(d_model, d_model)

    def forward(self, x, context, mask=None):
        # x 是 decoder 序列（长 Tq），context 是 encoder 输出（长 Tk）
        B, Tq, _ = x.shape
        Tk = context.size(1)
        q = self.w_q(x).view(B, Tq, self.n_heads, self.d_k).transpose(1, 2)
        k = self.w_k(context).view(B, Tk, self.n_heads, self.d_k).transpose(1, 2)
        v = self.w_v(context).view(B, Tk, self.n_heads, self.d_k).transpose(1, 2)
        scores = q @ k.transpose(-2, -1) / math.sqrt(self.d_k)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float('-inf'))
        attn = scores.softmax(dim=-1)
        out = (attn @ v).transpose(1, 2).reshape(B, Tq, -1)
        return self.w_o(out)

# 输入输出样例：decoder 序列长 7，encoder 输出长 10
ca = CrossAttention(d_model=512, n_heads=8)
x = torch.randn(2, 7, 512)            # decoder 端
context = torch.randn(2, 10, 512)     # encoder 输出
print(ca(x, context).shape)           # torch.Size([2, 7, 512])
```

## KV Cache

CodeKy：[3056. 手撕MHA with KV Cache](https://codeky.online/problem/3724)
Deep-ML：[KV Cache for Efficient Autoregressive Attention](https://www.deep-ml.com/problems/376)
LeetGPU（相关）：[INT8 KV-Cache Attention](https://leetgpu.com/challenges/int8-kv-cache-attention)

自回归生成每加一个 token 都要对全部历史做注意力，如果每步都重算所有 Key、Value 就有大量重复计算。KV Cache 把历史的 K、V 缓存下来，每步只对新 token 算 Q、K、V，再把新的 K、V 拼到缓存后面，复杂度从每步 O(T²) 降到 O(T)。新 token 的 Q 只有一行，但要和缓存里的全部 K 做注意力。

```python
import torch
import torch.nn as nn
import math

class CachedSelfAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        self.w_q = nn.Linear(d_model, d_model)
        self.w_k = nn.Linear(d_model, d_model)
        self.w_v = nn.Linear(d_model, d_model)
        self.w_o = nn.Linear(d_model, d_model)

    def forward(self, x, cache=None):
        # 增量解码时 x 形状为 (B, 1, d_model)，只含当前新 token
        B, T, _ = x.shape
        q = self.w_q(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        k = self.w_k(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        v = self.w_v(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        if cache is not None:
            k = torch.cat([cache['k'], k], dim=2)    # 在序列维拼接历史 K
            v = torch.cat([cache['v'], v], dim=2)    # 在序列维拼接历史 V
        new_cache = {'k': k, 'v': v}
        scores = q @ k.transpose(-2, -1) / math.sqrt(self.d_k)
        attn = scores.softmax(dim=-1)
        out = (attn @ v).transpose(1, 2).reshape(B, T, -1)
        return self.w_o(out), new_cache

# 输入输出样例：逐步喂入 3 个 token，缓存的 K 序列长度随之增长
attn = CachedSelfAttention(d_model=512, n_heads=8)
cache = None
for t in range(3):
    x = torch.randn(1, 1, 512)
    out, cache = attn(x, cache)
print(out.shape, cache['k'].shape)   # torch.Size([1, 1, 512]) torch.Size([1, 8, 3, 64])
```
